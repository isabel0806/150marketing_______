# LinkedIn Profile Optimizer

Audit the nine components of a LinkedIn profile against current best practices, then rewrite each section that needs it.

## When to use

- User pastes their profile content/sections and asks for an audit
- User wants to rewrite their headline, About section, or Featured section
- User is launching a content strategy and needs the profile to match
- Any of: "review my profile", "fix my headline", "optimize bio", "profile audit"

## Input

- Current profile content (paste of each section, or a description)
- Goal: **clients** / **job seeking** / **authority** — Featured section and CTA vary by goal
- Optional: draft rewrites to grade against the existing profile

## Output

1. **Scorecard** — all 9 sections, pass / fail / needs-work
2. **Priority fixes** — ranked by impact
3. **Before → After rewrites** for each failing section
4. **Expected uplift** — based on the benchmark data below

## Nine-component scorecard

| # | Section | Pass criteria |
|---|---------|----------------------|
| 1 | **Photo** | ≥400x400, face fills ~60% of frame, recent, natural light, slight smile |
| 2 | **Banner** | 1584x396, text in right 2/3, high contrast, includes value prop + CTA, readable on mobile |
| 3 | **Headline** | Uses all 220 chars; format `[What You Do] \| [Who You Help] [Result]` |
| 4 | **About** | 200-300 words, first-person, 7-step structure, hook in first 265-275 chars before "see more" |
| 5 | **Featured** | 3 items, matched to goal, custom thumbnails |
| 6 | **Experience** | Every bullet = action verb + metric, 5+ skills per role |
| 7 | **Skills** | ~50 listed, top 3 pinned, mirrors target roles |
| 8 | **Custom URL** | `linkedin.com/in/firstnamelastname`, not the default hash |
| 9 | **Recommendations** | At least 3 recent, specific (not generic), from diverse contexts |

## Steps

1. **Intake.** Collect current profile content + goal. Flag missing sections.
2. **Score each section** against the checklist above.
3. **Rewrite headline** as `[What You Do] | [Who You Help] [Achieve What Result]`, filling the 220-char budget.
4. **Rebuild About** with a 7-step structure (hook → credibility → turning point → what you do now → proof → invitation → CTA); verify the first 265-275 chars work as a standalone hook before "see more".
5. **Curate Featured** (3 items) matched to the goal:
   - **Clients:** lead magnet + case study with results + calendar/contact link
   - **Job seeking:** portfolio + best work samples + top-performing post
   - **Authority:** best content + media/podcast features + newsletter signup
6. **Rewrite Experience bullets** as `action verb + specific metric`. Suggest 5+ skills per role.
7. **Flag custom URL** if it's still the default hash.
8. **Draft recommendation-request messages** that name a specific project/skill instead of using LinkedIn's generic template.
9. **Deliver the before/after diff** with expected uplift.

## Benchmarks to cite

- Optimized About sections: ~3.9x more profile views
- 5+ listed skills: ~3x more connection requests
- Comprehensive profile: ~71% more likely to land interviews
- Featured section content: ~30% longer viewing time
- Personal profile vs. company page: far higher engagement and conversion on personal posts

## Hard rules

- First person ("I help...") never third person ("Jane is a passionate...")
- Never "passionate thought leader" / "driven professional" / "results-oriented"
- Avoid wall-of-text — use line breaks in the About section
- An empty Featured section is a free edge to fill — most profiles leave it blank
